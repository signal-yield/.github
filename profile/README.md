## Projects

### [tochi-satei-kun（土地査定クン）](https://github.com/signal-yield/tochi-satei-kun)

不動産鑑定士が公開する白箱方式の土地査定OSS。MLIT取引データからヘドニック回帰係数を都度推定し、業者用シートと顧客用シートを生成します。
Open-source land price assessment tool using a transparent white-box approach. Re-estimates hedonic coefficients from MLIT transaction data and generates professional and customer-facing assessment sheets.

### [revenue-kun（収益還元クン）](https://github.com/signal-yield/revenue-kun)

直接還元法による収益試算 CLI。レントロールと前提条件から NOI・収益試算値・感応度分析を出力します。
CLI tool for direct capitalization. Computes NOI, an indicated value, and sensitivity analysis from a rent roll and assumptions file.

### [jucho-kun（重調クン）](https://github.com/signal-yield/jucho-kun)

重要事項説明調査の一次スクリーニングスキル（Claude Cowork）。物件住所から調査チェックリストを生成し、取得済み書類の要点を抽出して xlsx 報告書を出力します。
A Claude Cowork skill for preliminary real estate due diligence, including Article 35-related investigation workflows in Japan. Generates checklists from a property address and extracts key facts from uploaded documents.
